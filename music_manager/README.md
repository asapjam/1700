# Music Manager v1.1
Option 2: Music Library Manager 1.1

Setup & Run:
- Open terminal
- Navigate to "music_manager" folder via "cd <file_path>"
- run via "dotnet run"

Features:
- Create Songs, Albums, and Artists
- Edit Songs & Albums
- Delete Songs & Albums
- Access related assets via the "Details" page for each entry
- Minimal API for Songs Database
- Cool photo on main page
